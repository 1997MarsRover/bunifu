# Photo Dump Uploads

Add photos to the folder that matches the moment/category:

- `outreach`
- `robotics`
- `startup-africa`
- `workshop`
- `team`
- `stem`
- `moments`
- `competitions`

The site automatically reads images from these folders at build time. Uploaded photos use the folder's category label and description, so long camera or WhatsApp filenames will not appear on the website.

You can still use descriptive filenames to keep the folder organized. For example:

```text
outreach/student-laptop-session.jpeg
robotics/line-following-robot.webp
```

Supported formats: `.avif`, `.jpg`, `.jpeg`, `.png`, `.webp`.
