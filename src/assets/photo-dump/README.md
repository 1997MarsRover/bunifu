# Photo Dump Uploads

Add photos to the folder that matches the moment/category:

- `outreach`
- `robotics`
- `startup-africa`
- `workshop`
- `team`
- `stem`
- `moments`

The site automatically reads images from these folders at build time.

Use descriptive filenames because new uploads use the filename as the generated caption. For example:

```text
outreach/student-laptop-session.jpeg -> Student Laptop Session
robotics/line-following-robot.webp -> Line Following Robot
```

Supported formats: `.avif`, `.jpg`, `.jpeg`, `.png`, `.webp`.
